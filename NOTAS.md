\# Proyecto: SaaS de fidelización para restaurantes



Stack: Java 21, Spring Boot, Spring Security, JPA/Hibernate, MySQL, React + TypeScript.

Una sola app multi-restaurante: cada restaurante tiene su slug y sus propios clientes.

Regla: mínimo 12 horas entre visitas. El contador no se guarda, se calcula.
